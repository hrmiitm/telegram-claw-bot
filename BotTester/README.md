# Telegram Bot Evaluator

This folder contains an automated testing suite designed to evaluate Telegram Chatbots built by students. Since the bots operate on the Telegram platform, standard HTTP tests cannot simulate a user messaging them (the Telegram Bot API explicitly prevents a Bot from interacting with another Bot).

To test the bots realistically, we use a **User Client** (via the `Telethon` library) that logs into a real Telegram account and automatically messages the bots exactly as a human user would.

## Prerequisites

1.  **Python 3.8+**
2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Telegram API Credentials:**
    Because the script logs into Telegram as a standard user, you need a User API ID and Hash.
    - Go to https://my.telegram.org and log in with your phone number.
    - Go to "API development tools" and create a new application to get your `api_id` and `api_hash`.
    - Export them as environment variables before running the script:
      ```bash
      export TELEGRAM_API_ID="your_api_id"
      export TELEGRAM_API_HASH="your_api_hash"
      ```

## File Structure

- `tester.py`: The main asynchronous testing script.
- `students.csv`: The input CSV file containing student information. Expected columns: `roll_no`, `bot_username`, `bot_token`.
- `test_data/`: A directory containing mock files to send to the bot (e.g., `sample_image.png` for OCR/data extraction testing).
- `test_results.db`: An SQLite database automatically generated by the script to robustly store test results, including any files (as BLOBs) returned by the bot.

## Test Cases Evaluated

1.  **Simple Text Q&A**: Sends `/start` and checks if the bot responds with any text to verify it is alive.
2.  **Image Data Extraction**: Sends `test_data/sample_image.png` and asks the bot to extract the text. Verifies that the bot correctly identifies the string `TEST1234`.
3.  **Context Management**: Sends "My favorite color is emerald." followed by a question "What is my favorite color?". Validates whether the bot remembers previous messages in the conversation by looking for "emerald" in the response.
4.  **Bot Data Send**: Asks the bot to send back a file or an image. Checks if the response contains media and saves the media directly into the SQLite database as a BLOB.

## Running the Evaluator

Run the script from within this directory:

```bash
python tester.py
```

*Note: On the first run, `Telethon` will prompt you to log into your Telegram account (you will be asked to enter your phone number and the login code sent to your Telegram app).*

## Viewing Results

You can view the results stored in `test_results.db` using any standard SQLite viewer (like `sqlite3` CLI, DB Browser for SQLite, or DBeaver).
